# Frontend

Angular-Prüfwerkstatt: Arbeitskörbe | Vorgänge | Fallakte. Gestaltung mit dem lokal eingebundenen Astryx-Theme (`src/vendor/astryx`, MIT), Texte in `src/app/de.ts`.

```bash
npm ci
npm start          # http://localhost:4200, /api wird an localhost:8080 weitergeleitet
npm run lint
npx ng test --watch=false
```
